Đang chờ bị loại bỏ trong Python 3.14
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

* Trường ``ma_version_tag`` trong :c:type:`PyDictObject` dành cho các extension module (:pep:`699`; :gh:`101193`).

* Tạo :c:data:`các kiểu bất biến <Py_TPFLAGS_IMMUTABLETYPE>` với các lớp cơ sở có thể thay đổi (:gh:`95388`).
