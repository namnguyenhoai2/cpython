**********************
Trình soạn thảo và IDE
**********************

Có một số IDE hỗ trợ ngôn ngữ lập trình Python. Nhiều trình soạn thảo và IDE cung cấp tính năng tô sáng cú pháp, công cụ gỡ lỗi và các bước kiểm tra :pep:`8`.


IDLE --- trình soạn thảo và shell Python
========================================

IDLE là Môi trường Tích hợp Phát triển và Học tập của Python, thường được cài sẵn cùng Python. Nếu bạn đang dùng Linux và chưa cài IDLE, hãy xem :ref:`Cài đặt IDLE trên Linux <installing_idle_on_linux>`. Để biết thêm thông tin, hãy xem :ref:`tài liệu IDLE <idle>`.


Các trình soạn thảo và IDE khác
===============================

Wiki cộng đồng Python có thông tin do cộng đồng đóng góp về các trình soạn thảo và IDE. Vui lòng truy cập `Trình soạn thảo Python <https://wiki.python.org/moin/PythonEditors>`_ và `Môi trường Phát triển Tích hợp <https://wiki.python.org/moin/IntegratedDevelopmentEnvironments>`_ để xem danh sách đầy đủ.
