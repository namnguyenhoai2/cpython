:mod:`!imp` --- Truy cập nội bộ import
======================================

.. module:: imp
   :synopsis: Đã bị loại bỏ trong 3.12.
   :deprecated:

.. deprecated-removed:: 3.4 3.12

Mô-đun này không còn thuộc thư viện chuẩn Python. Mô-đun đã được :ref:`loại bỏ trong Python 3.12 <whatsnew312-removed-imp>` sau khi không còn được khuyến nghị sử dụng trong Python 3.4.

:ref:`Thông báo loại bỏ <whatsnew312-removed-imp>` bao gồm hướng dẫn di chuyển mã từ :mod:`!imp` sang :mod:`importlib`.

Phiên bản Python cuối cùng cung cấp mô-đun :mod:`!imp` là `Python 3.11 <https://docs.python.org/3.11/library/imp.html>`_.

.. _`Python 3.11`: https://docs.python.org/3.11/library/imp.html
