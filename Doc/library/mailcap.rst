:mod:`!mailcap` --- Xử lý tệp Mailcap
=====================================

.. module:: mailcap
   :synopsis: Đã bị loại bỏ trong phiên bản 3.13.
   :deprecated:

.. deprecated-removed:: 3.11 3.13

Mô-đun này không còn thuộc thư viện chuẩn Python. Mô-đun đã bị :ref:`loại bỏ trong Python 3.13 <whatsnew313-pep594>` sau khi bị phản đối trong Python 3.11. Việc loại bỏ đã được quyết định trong :pep:`594`.

Phiên bản Python cuối cùng cung cấp mô-đun :mod:`!mailcap` là `Python 3.12 <https://docs.python.org/3.12/library/mailcap.html>`_.

.. _`Python 3.12`: https://docs.python.org/3.12/library/mailcap.html
