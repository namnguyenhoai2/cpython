################
Hướng dẫn Python
################

.. Tip:: Hướng dẫn này dành cho *lập trình viên* mới làm quen với ngôn ngữ Python, **không phải** *người mới bắt đầu* mới làm quen với lập trình.

Python là một ngôn ngữ lập trình mạnh mẽ và dễ học. Ngôn ngữ này có các cấu trúc dữ liệu cấp cao hiệu quả cùng cách tiếp cận đơn giản nhưng hiệu quả đối với lập trình hướng đối tượng. Cú pháp thanh lịch và kiểu dữ liệu động của Python, cùng với bản chất thông dịch, khiến Python trở thành ngôn ngữ lý tưởng để viết script và phát triển ứng dụng nhanh trong nhiều lĩnh vực trên hầu hết các nền tảng.

Trình thông dịch Python và thư viện chuẩn phong phú được cung cấp miễn phí ở dạng mã nguồn hoặc nhị phân cho tất cả các nền tảng chính từ trang web Python, https://www.python.org/, và có thể được tự do phân phối. Trang web này cũng chứa các bản phân phối và liên kết đến nhiều mô-đun, chương trình và công cụ Python miễn phí của bên thứ ba, cùng tài liệu bổ sung.

Trình thông dịch Python có thể dễ dàng được mở rộng bằng các hàm và kiểu dữ liệu mới được triển khai bằng C hoặc C++ (hoặc các ngôn ngữ khác có thể được gọi từ C). Python cũng phù hợp làm ngôn ngữ mở rộng cho các ứng dụng có thể tùy chỉnh.

Hướng dẫn này giới thiệu không chính thức cho người đọc các khái niệm và tính năng cơ bản của ngôn ngữ và hệ thống Python. Lưu ý rằng bạn cần có hiểu biết cơ bản về lập trình nói chung. Bạn nên có sẵn một trình thông dịch Python để thực hành, nhưng tất cả các ví dụ đều độc lập, vì vậy bạn cũng có thể đọc hướng dẫn này khi ngoại tuyến.

Để biết mô tả về các đối tượng và mô-đun chuẩn, hãy xem :ref:`builtins-index` và
:ref:`library-index`. :ref:`reference-index` cung cấp định nghĩa chính thức hơn về ngôn ngữ. Để viết các phần mở rộng bằng C hoặc C++, hãy đọc :ref:`extending-index` và
:ref:`c-api-index`. Ngoài ra còn có một số sách trình bày chuyên sâu về Python.

Hướng dẫn này không nhằm mục đích trình bày toàn diện và bao quát mọi tính năng, hay thậm chí mọi tính năng thường được sử dụng. Thay vào đó, hướng dẫn giới thiệu nhiều tính năng đáng chú ý nhất của Python và giúp bạn hiểu rõ về sắc thái cũng như phong cách của ngôn ngữ này. Sau khi đọc, bạn sẽ có thể đọc và viết các module và chương trình Python, đồng thời sẵn sàng tìm hiểu thêm về các module thư viện Python khác nhau được mô tả trong :ref:`library-index`.

Bạn cũng nên xem qua :ref:`glossary`.
